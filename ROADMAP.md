# Roadmap

Planned milestones for ghostty-mirror.nvim.

## 0.1.0 — Theme auto-generation

Generate a Ghostty theme on the fly from the active colorscheme's live
highlights when no hand-made/cached file exists, so any colorscheme mirrors
without manual authoring.

## 0.2.0 — tmux support

Mirror the active colorscheme into tmux as well, keeping terminal, Ghostty,
and tmux in sync on `:colorscheme`.
